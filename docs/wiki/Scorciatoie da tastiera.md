# Scorciatoie da tastiera

Solo tasti singoli, senza Ctrl/⌘/Alt: sono uguali su Windows e Mac. Non funzionano mentre scrivi in un campo o con una finestra aperta.

| Tasto | Azione |
|---|---|
| `1`–`5` | Vai a Oggi, Dispensa, Cucina, Spesa, Tu |
| `N` | Aggiungi un prodotto |
| `S` | Aggiungi da scontrino (foto o PDF) |
| `V` | Aggiungi a voce |
| `C` | Cosa cucino stasera? |
| `P` | Aggiungi un pasto |
| `\` | Cerca in dispensa |
| `?` | Mostra le scorciatoie |
| `Esc` | Chiudi finestra, ricerca o dettaglio; riduci la sezione espansa |

`S` e `V` richiedono la chiave Gemini.
